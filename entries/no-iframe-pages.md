## 什么情况下会遇到

手里有一个现成的网页，或者觉得写独立 HTML 更顺手，于是让插件后台把页面吐出来，在宿主里用 iframe 嵌一下。

## 该怎么做

把页面写成 React 组件，注册到展位里。

iframe 里的文档拿不到宿主的主题变量，不会跟着深色浅色切换，也拿不到宿主的语言设置。看上去就是宿主里贴了一块外来的东西，而且这些事后补不回来。

## 证据

- 官方说明：0.2.2-rc.1 安装包内置的插件开发说明在界面一节写明，不要从 Host 提供 HTML 页面再用 iframe 嵌入，并列出了 iframe 文档收不到的三样东西：主题变量、明暗切换、语言。
