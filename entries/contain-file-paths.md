## 什么情况下会遇到

插件有一个「按名字取文件」的接口，比如取作品、取图片、取静态资源，直接把请求里的路径拼到目录后面去读。

## 该怎么做

读之前做三道检查：

- 路径任何一段以 `.` 开头就拒绝（挡住 `..` 和点文件）。
- 拼好之后确认还在目录里面。
- 对目录和文件都取真实路径（`realpath`）再比一次，挡住指到目录外面的符号链接。

文件名形式固定的，直接用一个严格的正则限制文件名更省事。

## 证据

- 公开仓库：dsh-guizang-design 0.1.4 的 `lib/index.js` 里有一个专门的函数做这三道检查，注释写的是只在目录里面找文件，拒绝 `..`、点文件和目录外的符号链接。
- 公开仓库：dsh-media-desk 2.6.2 的 `src/host.js` 对文件名用 `^[\w.-]+$` 做限制，不符合就返回 400。
