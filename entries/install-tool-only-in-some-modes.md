## 什么情况下会遇到

在某个模式的对话里让模型帮你装一个插件，或者把刚写好的插件装上。模型说做不到，或者绕来绕去让你自己去命令行装。

## 该怎么做

装插件靠的是 `plugin_manager` 这个工具。它默认只在标准模式和创造模式里开着，其他模式里是关的。要让模型装插件，换到创造模式开一个新会话。

另外，没有开完全访问权限时，`plugin_manager` 的每一次调用都要你批准，包括只是列一下已装了什么。所以别让模型反复去列，需要的时候再调。

## 证据

- 官方说明：0.2.2-rc.1 安装包内置的插件管理说明写明，`plugin_manager` 工具在 Standard 和 Creator 两个预设里启用，其他 Web 预设默认关闭；没有完全访问权限时每个动作都需要批准。
- 公开文章：《DeepSeek Harness 发布创造模式，需要什么插件，自己造。我也写了一个》，作者「Ai学习的老章」，人人都是产品经理，2026-11-04。文中的说法是标准、PTC、极简三种模式都装不了，只有创造模式能装。

## 备注

公开文章说标准模式也装不了，和 0.2.2-rc.1 的内置说明对不上。文章没写它用的宿主版本，可能是版本不同。这条按内置说明写；你那里不一样的话，以实际为准，也欢迎来改。
