## 什么情况下会遇到

插件做了中英两份文案。加新文案时只加了一边，或者占位符写得不一样；用户切到另一种语言，界面上漏出 key 名，或者一半中文一半英文。

## 该怎么做

- 语言跟着宿主的语言服务走，监听它的变化。老版本宿主没有这个服务时，退回浏览器语言。
- 写一个测试：两份词典的 key 集合完全一样，占位符一致，英文那份里没有中文，代码和页面里用到的每个 key 都在词典里。

## 证据

- 公开仓库：dsh-guizang-design 0.1.4 的 `lib/client.js` 用 `ctx.inject(['locale'], ...)` 读语言并监听 `locale/change`，注释写明老版本没有这个服务时跟随浏览器语言；`test/plugin.test.mjs` 里有一个测试正是检查上面四件事。
- 公开仓库：DSH-better-sidebar 0.30.1 的 `tests/locales.spec.ts` 同样断言各语言的 key 集合相同。
- 官方说明：0.2.2-rc.1 内置的创造说明要求界面上可见的文字经过客户端的语言服务。
