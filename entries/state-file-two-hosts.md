## 什么情况下会遇到

插件把数据存成自己的一个 JSON 文件。用户同时开着桌面版和网页版，就是两个宿主进程在读写同一个文件；或者写到一半进程被杀，文件只剩半截。

## 该怎么做

- 写入时先写到临时文件，再用改名替换正式文件，这样不会出现半截文件。
- 同一进程里的写操作排成一队，一个一个来。
- 每次读写前比一下文件的修改时间，变了就重新读，别用内存里的旧数据盖掉另一个进程刚写的。
- 每次从文件读进来都过一遍迁移函数，把旧版本缺的字段补上。

## 证据

- 公开仓库：dsh-media-desk 2.6.2 的 `src/store.js`。文件开头的注释写明桌面端和 Web 端读同一份数据、两个 Host 进程可能同时运行，所以每次写入前按修改时间判断要不要重读；写入用「临时文件加改名」；写操作经一个队列串行执行；读入时调用迁移函数。
