## 什么情况下会遇到

插件要用户填一个 API Key。存的时候和别的设置放在一起，取设置的接口把整份设置原样发给界面，密钥就跟着到了浏览器里。

## 该怎么做

- 存密钥的文件权限设成只有本人可读写（0600）。
- 给界面的那份设置里去掉密钥本身，只带两样：有没有填过、末四位。
- 更新设置时，界面没传新密钥就保留原来的；要清空就用一个明确的「清除」标记，别把空字符串当成清空。

## 证据

- 公开仓库：dsh-media-desk 2.6.2 的 `src/settings.js`。写设置文件时指定 `mode: 0o600` 并再 `chmod` 一次；有一个专门生成「发给浏览器的版本」的函数，注释写的是只告诉它有没有密钥和末四位；更新逻辑里只有非空的新密钥才覆盖，另有单独的清除标记。
