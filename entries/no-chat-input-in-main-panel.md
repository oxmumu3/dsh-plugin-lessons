## 什么情况下会遇到

做一个有自己页面的插件（注册到 `main` 展位），想在页面里放一个输入框，让用户在这里和模型对话。

## 该怎么做

独立面板里自己画的输入框拿不到宿主输入框的能力（`inputActions`），也不会自动带上多轮上下文。做出来的东西看着像聊天，其实每一句都是从头开始。

对话优先挂到会话视图的展位（`conversation.view` 一带），或者嵌入宿主原生的会话组件。自己的页面只负责展示和整理结果。

## 证据

- 经验做法：「发现好插件」内置清单，来自作者做多个插件时的记录，没有留下当时的版本。
- 宿主代码：0.2.2-rc.1 里 `main` 和 `conversation.view` 两个展位都存在；`inputActions` 是会话界面服务随会话绑定提供的标准 prop。

## 还没核对的

「注册到 `main` 的面板拿不到 `inputActions`、没有多轮记忆」是作者的经验。这次只核对到 `inputActions` 由会话层提供，没有在宿主里实际注册一个 main 面板去试拿不拿得到。动手前请用 `cordis_inspect_query` 查一下 `main` 展位在你这个版本上给了哪些 props。
