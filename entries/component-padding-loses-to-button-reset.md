## 什么情况下会遇到

组件是 `<button>`（大格子、页签、发送键、选项行），自己也写了 `padding`，渲染出来文字却顶着边框。查 computed style 才发现 `padding: 0`。

## 该怎么做

reset 写成 `.x button{padding:0}` 时，它的特异性是 0,1,1；单类选择器 `.x-zone{padding:14px 16px}` 是 0,1,0，**输给 reset**。

所有靠内边距撑形状的按钮类，选择器一律写到两级：

```css
.x .x-zone { padding:14px 16px }
.x .x-tab  { padding:6px 14px }
```

单测里加一条：凡是这类按钮组件，都必须匹配 `'.x .x-组件名{'`，写成单级就红。

## 证据

- 本人实测：2026-11-14，面板五格的数字离边框只有 1–3px，期望 16px；computed padding 为 0。
- 本人实测：同一样式表里 `.x-btn` 早就用 `.x .x-btn` 写对了，说明同类问题之前已经踩过一次，只是没推广到其他组件。
