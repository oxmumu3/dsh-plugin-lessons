## 什么情况下会遇到

给注册到 `main` 展位的页面写最外层容器，想让它撑满整个区域，用了 `position: absolute; inset: 0`。

## 该怎么做

```css
.my-plugin-root { flex: 1 1 0; height: 100%; min-height: 0; }
```

绝对定位铺满会盖住左侧栏。用户点不到侧栏，就回不去别的页面了。
