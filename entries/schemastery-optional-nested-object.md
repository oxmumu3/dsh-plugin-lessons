分类: 接口与注册
状态: 有效
宿主版本: 0.2.1-rc.2
最近核对: 2026-11-10

## 什么情况下会遇到

Config 里有一个可选的嵌套配置，比如「备用路由」，里面有两个必填字段。用户没配它，插件一启动就报这两个字段缺失。

## 该怎么做

Schemastery 的 `z.object()` 带一个隐含的默认值 `{}`。用户没写这一项时，它被补成空对象，再拿去校验，必填字段自然不满足。

可选的嵌套对象要把「没有」明确写出来：

```ts
const fallbackRoute = z.union([
  z.object({provider: z.string().required(), model: z.string().required()}),
  z.const(undefined),
]);
```

只允许出现其中一边的结构（比如只有 `allow` 或只有 `deny`）也是同样的坑，同样处理。

## 证据

- 公开仓库：dsh-agent-teams 0.1.29 的 `src/index.ts`。注释写明 `z.object()` 在 Schemastery 里有隐含的 `{}` 默认值，可选项要显式建模为「不存在」，否则缺失的路由会被当成空对象校验并在必填键上失败；代码即上面的写法，并注明工具策略有同样的问题。
